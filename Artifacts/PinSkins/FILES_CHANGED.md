# Pin skin system: files created

No pre-existing model, material, gameplay script or scene file was modified.

Use Assets/DetectiveDesk/Prefabs/CollectiblePin.prefab. The imported model remains linked and untouched.

Ruby is the default. SetSkin(1) selects Sapphire. Choose any of the 12 names in the custom Inspector for Edit Mode preview.

The two-instance tests ran in an isolated Unity preview scene; the detective scene was not edited.
