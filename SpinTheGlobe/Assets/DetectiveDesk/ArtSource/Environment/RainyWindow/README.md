# Rainy window

Goal: Frame/mullions only; rain shader in Unity.

Run: `blender --background --python "Assets/DetectiveDesk/ArtSource/Environment/RainyWindow/build_asset.py"` from Unity project root.

Outputs: RainyWindow.blend (editable Blender source with embedded generator); RainyWindow.fbx (if Blender FBX exporter succeeds).

This is a structured procedural **starter**, not a reference-matched high-detail model. For final quality: refine the geometry/materials in this source script, regenerate, then check Game camera in Unity.

See References/ for inspiration, and do not modify existing Unity prefabs or their scripts without a backup.
