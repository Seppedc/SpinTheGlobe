# Whiskey glass

Goal: Heavy faceted glass, amber liquid and ice.

Run: `blender --background --python "Assets/DetectiveDesk/ArtSource/Props/WhiskeyGlass/build_asset.py"` from Unity project root.

Outputs: WhiskeyGlass.blend (editable Blender source with embedded generator); WhiskeyGlass.fbx (if Blender FBX exporter succeeds).

This is a structured procedural **starter**, not a reference-matched high-detail model. For final quality: refine the geometry/materials in this source script, regenerate, then check Game camera in Unity.
