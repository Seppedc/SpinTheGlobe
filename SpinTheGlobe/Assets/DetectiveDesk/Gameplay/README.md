# DetectiveDesk gameplay integration

The saved DetectiveOffice scene uses one GameManager on the existing root, one GlobeController on MechanicalGlobe, and the original DetectiveGame as the HUD/case adapter. Existing settings, archive, files, stamp, completion animation, camera, lights, models and materials remain bound. Upgrades uses the existing modal with six persistent purchase callbacks. The third Commissioner display reuses the authored review-prefab assembly and display base; original figures keep their Edit Mode poses.

Drag the globe left to right, choose a color in the coffer, then click inside one of the eight outlined countries. Country recognition uses the retained Natural Earth polygons and holes, calibrated to the artwork's geographic rectangle. Pins launch from the original muzzle, arrive after 0.32 seconds, and create corresponding globe markers. Only forward wire crossings and full origin revolutions award income. The HUD per-minute figure is an estimate, never a passive reward.

Data/UpgradeConfig.asset contains provisional configurable balance: 30 degrees/second initial ceiling (5 RPM), +15 per speed level, 6 degrees/second per motor level, 0.985 friction at 60 Hz, base revolution reward 1; starting costs speed 75, motor 100, durability 60, restoration 120; growth 1.8 and maximum upgrade level 10. Twelve skin multipliers are 1, making colors cosmetic. At Play Start only empty coffer slots are filled. Their collectibles are unlimited reusable selected-color ammunition. No save, offline-income format or PlayerPrefs persistence was added.

Three restoration multipliers SUM from 3 initially to 9 when complete. The initial art scatters existing authored bust parts onto their plinth seats, then restores them with runtime stone/gold property blocks and dark/gold line seams. This is provisional disassembled-part art, not fracture-sculpted porcelain. Base/plinth materials are excluded. FigurinePedestal.authoredTierVisuals accepts four final authored tier sets later. No meshes or shared art material assets were edited or generated.

References/ retains the input country JSON, Natural Earth source GeoJSON and provenance. All polygon coordinates are retained in the CountryData assets. USA/GBR/BEL/FRA/BRA/JPN/AUS/EGY are the initial playable set. Belgium's base value is 12 and USA's is 2. Country outlines split longitude jumps and do not cover artwork titles or footers.

Editor validation is opt-in: GameplayMathValidation.Run executes production math and polygon checks; GameplayRuntimeValidation.Arm starts a temporary Play Mode coroutine harness. It clones the configuration in memory, uses temporary test currency and upgrade state, captures two active pins, and exits Play Mode. It never writes test state into data assets or PlayerPrefs. Exact crossing assertions explicitly step the production GlobeController between actual coroutine frames with automatic Update temporarily disabled. Physical mouse input was not synthesized; callbacks and camera ray picking were exercised. Logs and 1920x1080 HUD-inclusive captures are in ProductionLogs/Gameplay.

The project now uses the installed PhysX integration. The previous None fallback disabled all physics operations. Only PhysicsManager.m_CurrentBackendId changed, using the normal Project Settings dropdown followed by a same-version editor restart; the original settings are backed up in ProductionLogs/Gameplay/Checkpoint. Public Physics.GetCurrentIntegrationInfo confirms PhysX is active. Real ray acquisition of the original globe collider, all twelve coffer slots, all eight map targets, an actual obstruction, gravity-driven drops and desk contact passed the 126-check Play harness. The original broad interaction boxes remain unchanged; map occlusion refines those boxes against active authored visual bounds so empty interaction space does not hide countries. This is conservative bounds-based occlusion near object silhouettes.

TachometerUI owns the original DetectiveGlobeMechanism.rpmNeedle (RPMGauge_NeedlePivot); the GlobeRework_Needle visual child keeps its original identity pose. The original pivot's 72-degree Edit Mode pose is preserved. Actual RPM/MAX is shown on a compact world-space canvas beside the dial, without moving the existing HUD. Dropped pins use configurable WallMapManager.dropOutwardSpeed (1.8 m/s) to pop across the gap from board to desk; gravity and the existing desk collider determine their fall and landing.

GameplayIntegration.Setup is the initial editor setup helper and intentionally refuses a scene already containing a GameManager. Do not rerun it to update wiring. The initial scene copy and serialized component baseline are in ProductionLogs/Gameplay/Checkpoint and integration-components-before.json. No new case story or progression was designed.

Final focused regression: GlobeController.Update calls CanBeginDrag, which requires the unchanged original physical collider hit and a forward intersection with the visible globe sphere. Actual Play assertions accept the globe-center ray and reject the Brazil map ray, preventing map clicks inside the generous legacy box from also acquiring globe drag. The final run passed 126 runtime checks and 31 production math assertions; scene and protected-asset preservation were rechecked.
