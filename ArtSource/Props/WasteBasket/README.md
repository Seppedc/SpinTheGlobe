# WasteBasket

Canonical editable source: WasteBasket.blend, with embedded generator. Rebuild using:

`powershell -NoProfile -ExecutionPolicy Bypass -File Tools/build-blender-asset.ps1 -Asset WasteBasket -ExportFbx -Publish`
