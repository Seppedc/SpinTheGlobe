# Detective desk

Goal: Thick top, beveled perimeter, scratch-ready walnut, brass border.

Run: `blender --background --python "ArtSource/Environment/DetectiveDesk/build_asset.py"` from Unity project root.

Outputs: DetectiveDesk.blend (editable Blender source with embedded generator); DetectiveDesk.fbx (if Blender FBX exporter succeeds).

This is a structured procedural **starter**, not a reference-matched high-detail model. For final quality: refine the geometry/materials in this source script, regenerate, then check Game camera in Unity.
